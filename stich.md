# Stitch AI Prompt — Cover Slide JagaDosis

## Objective
Create a single presentation cover slide (16:9) for a Flutter application named **JagaDosis**. The design should look premium, elegant, clean, and suitable for a university project presentation.

---

# Style

- Modern, elegant, and minimalistic.
- Healthcare-inspired visual identity.
- Bright theme (do **not** use dark mode).
- Premium startup presentation aesthetic.
- Clean layout with generous whitespace.
- Soft gradients and subtle glassmorphism.
- Smooth rounded corners.
- Soft shadows.
- Professional and trustworthy appearance.

---

# Color Palette

Background:
- #F8FBFF

Primary:
- #2E90FA

Secondary:
- #14B8A6

Accent:
- #60A5FA

Neutral:
- White
- Light Gray (#E5E7EB)

Use colors sparingly to maintain a clean and elegant appearance.

---

# Layout

Split the slide into two sections.

## Left Section (40%)

Display the following text:

### Title

JagaDosis

Large, bold, premium typography.

---

### Subtitle

Flutter APP

Medium weight.

---

### Description

Aplikasi Pengingat Minum Obat

Smaller than subtitle.

---

### Presenter

Aryo Putranto Pramudityas

Place near the bottom-left with a lighter font weight.

---

## Right Section (60%)

Create one large floating **3D smartphone mockup**.

Requirements:

- Modern bezel.
- Premium appearance.
- Slight perspective view.
- Soft realistic shadow.
- Floating effect.
- High-quality render.
- Rounded corners.

The smartphone display should contain a **placeholder frame** where an application screenshot or slide can easily be inserted later. Do **not** generate any UI inside the screen—leave it ready for replacement.

---

# Background Elements

Keep the background subtle and uncluttered.

Include:

- Soft blue gradient blobs.
- Thin curved lines.
- Rounded transparent cards.
- Small circles.
- Tiny "+" medical symbols.
- Very subtle heartbeat-inspired curves.
- Light glassmorphism shapes.
- Soft floating geometric accents.

Avoid excessive decorations.

---

# Typography

Use a modern sans-serif font similar to:

- Inter
- SF Pro Display
- Poppins

Hierarchy:

- Large bold title
- Medium subtitle
- Small description
- Small presenter name

Maintain consistent spacing and alignment.

---

# Visual Mood

The design should communicate:

- Healthcare
- Precision
- Trust
- Simplicity
- Innovation
- Professionalism
- Premium Flutter application
- Modern startup branding

---

# Composition

The smartphone should become the main visual focus.

The text should balance the composition without overpowering the phone.

Use generous whitespace for a premium look.

---

# Output Requirements

- Presentation cover slide
- Aspect ratio 16:9
- High-resolution
- Fully editable layout
- Modern presentation quality
- Suitable for academic and professional presentations

The final result should resemble a polished keynote or Apple-style presentation slide, with a clean medical theme and a premium floating 3D smartphone ready to showcase the JagaDosis application.
